# Projeto de Pensamento Computacional
Este repositório abriga o código fonte de meu projeto do 2º Bimestre da matéria de Pensamento Computacional, do curso de Análise e Desenvolvimento de Sistemas da Universidade do Oeste Paulista.

## Sobre
O projeto é um programa de gerenciamento para uma academia, permitindo controle sobre o time de instrutores, quantidade e identificação de alunos, preços das mensalidades e identifiação das modalidades.
O objetivo da realização do projeto é desenvolver e demonstrar a capacidade de resolução de problemas ecriar algoritmos que atendam as mais variadas situações do cotidiano do mercado de trabalho.

## Funcionalidades
* Cadastrar instrutores, alunos e modalidades de treino;
* Exclusão de instrutores, alunos e modalidades;
* Lançamento de avaliação física;
* Relatórios (lista de instrutores, alunos, modalidades e avaliações físicas).

## Features adicionais
 * Codificação UTF-8 (pode ter problemas ao exibir o código fonte, mas é exibido corretamente na execução do programa);
 * Suporte a cores para melhor feedback ao usuário;
 * Terminal e menus limpos.
